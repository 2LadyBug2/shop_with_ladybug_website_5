# Shop with LadyBug  A luxury personal-shopper website concept. Browse Dior, Chanel, Gucci and Prada, then request items from shoppers in Paris, Milan and London.  Plain HTML and CSS, no build step. Open `index.html` in a browser to start.  Pages: Home, Shop, How It Works, About, Contact, My Requests. Forms are demo only and send nothing.
